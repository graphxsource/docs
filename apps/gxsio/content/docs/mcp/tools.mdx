## Tools Overview

This MCP currently exposes the following tools.

## Create Multiple Mockups

**Name:** `Create Multiple Mockups` (`create_multiple_mockups`)

**Purpose:**
Create mockups for multiple views of a single product, generating one mockup output per view.

**Input (example):**

```json
{
  "mockupRequestType": "Standard",
  "PONumber": "PO1234",
  "OutputFileFormat": "png",
  "mockupOrderProduct": {
    "productPartID": "B00445507",
    "supplierID": "50",
    "mockupRequestOrderProductViews": [
      {
        "productViewID": 1,
        "mockupRequestOrderProductViewLocations": [
          {
            "LocationName": "Full Front",
            "artURL": "https://example.com/artwork-front.png",
            "instructions": "",
            "heightInc": 5,
            "widthInc": 4.5,
            "embroidery": false,
            "removeBackground": true
          }
        ]
      },
      {
        "productViewID": 2,
        "mockupRequestOrderProductViewLocations": [
          {
            "LocationName": "Back",
            "artURL": "https://example.com/artwork-back.png"
          }
        ]
      }
    ]
  }
}
```

## Get Product Views

**Name:** `Get Product Views` (`get_product_views`)

**Purpose:**
Retrieve the available product views (angles) for a product part, used for mockup alignment.

**Input (example):**

```json
{
  "productPartId": "B00445507",
  "supplierId": "50"
}
```

**Output (placeholder):**

```json
{
  "tObject": [
    {
      "id": 38,
      "title": "1-M0-TShirts-WH"
    }
  ],
  "tObjectLst": null,
  "status": "1",
  "errorCode": null,
  "errorMessage": null,
  "extraData": null,
  "error": null
}
```
